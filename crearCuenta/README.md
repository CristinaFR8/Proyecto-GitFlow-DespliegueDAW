## Finalidad
Crear la página de registro para que los usuarios puedan crear una cuenta en la plataforma.

## Desarrollar la página de Crear cuenta incluyendo:

- Estructura HTML del formulario de registro.
- Campos necesarios para crear una cuenta.
- Nombre de usuario.
- Correo electrónico.
- Contraseña.
- Confirmación de contraseña.
- Botón para crear la cuenta.
- Mensajes o indicaciones básicas para facilitar el registro.
- Diseño visual mediante CSS.
- Integración con el header y la navegación principal.
- Adaptación básica a diferentes tamaños de pantalla.
